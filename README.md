# KidsPos

キッズ向けPOSシステム - Windows版

## 概要
キッズで使用している店舗管理・販売支援システムです。シンプルで使いやすいインターフェースで、日々の業務をサポートします。

## 主な機能
- 商品管理
- 売上管理
- 在庫管理
- レジ機能
- レポート出力

## システム要件

### 動作環境
- **OS**: Windows NT以降（Windows 10/11推奨）
- **Framework**: .NET Framework 4.0以上
- **メモリ**: 2GB以上推奨
- **ディスク容量**: 100MB以上の空き容量

## インストール方法

1. リポジトリをクローンまたはダウンロード
2. `bin`ディレクトリに移動
3. `PosSystem.exe`を実行

```cmd
cd bin
PosSystem.exe
```

## 使い方

### 初回起動
1. アプリケーションを起動
2. 初期設定ウィザードに従って設定
3. 商品マスタの登録

### 基本操作
- **商品登録**: メニューから「商品管理」を選択
- **売上記録**: レジ画面で商品をスキャンまたは選択
- **レポート確認**: 「レポート」メニューから各種帳票を出力

## アンインストール

アプリケーションファイルを削除するだけでアンインストール完了です。

## トラブルシューティング

### よくある問題
- **起動しない場合**: .NET Frameworkのバージョンを確認してください
- **エラーが表示される場合**: 管理者権限で実行してみてください
